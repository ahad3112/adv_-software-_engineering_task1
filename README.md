##  How It Works (CI/CD)
We created a GitHub Actions workflow (`.github/workflows/main.yml`) to handle the deployment automatically. 
Whenever we push new changes to the `main` branch, the workflow triggers, checks out the repository, and deploys the updated HTML/CSS files directly to GitHub Pages. This ensures the live site is always up to date without any manual steps.
